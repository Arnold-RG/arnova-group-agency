# Fonts, icons and media

## Typefaces (site default, Option 1 — Apex Navy)
- **Source Sans 3** by Adobe, SIL Open Font License 1.1. License: `assets/fonts/OFL-SourceSans3.txt`.
- **Newsreader** by Production Type, SIL Open Font License 1.1. License: `assets/fonts/OFL-Newsreader.txt`.

Both families are self-hosted as variable WOFF2 files in `assets/fonts/` so the site does not need a third-party font request.

Option 2 (Ridge Forest) is specified with Fraunces and Figtree, and Option 3 (Signal Slate) with Syne and Instrument Sans. Those families are also under the SIL Open Font License. They are not self-hosted in this commit; they would be added the same way if one of those options is chosen.

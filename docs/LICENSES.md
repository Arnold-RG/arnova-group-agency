# Fonts, icons and media

## Typefaces (site default, Option 3 — Signal Slate)
- **Instrument Sans** by Instrument, SIL Open Font License 1.1. License: `assets/fonts/OFL-InstrumentSans.txt`.
- **Syne** by Bonjour Monde, SIL Open Font License 1.1. License: `assets/fonts/OFL-Syne.txt`.
- **Fraunces** by Undercase Type, SIL Open Font License 1.1. License: `assets/fonts/OFL-Fraunces.txt`. Used for the homepage editorial hero.

These families are self-hosted as WOFF2 files in `assets/fonts/` so the site does not need a third-party font request.

Source Sans 3 and Newsreader remain in `assets/fonts/` for Option 1 (Apex Navy), under `OFL-SourceSans3.txt` and `OFL-Newsreader.txt`.
